# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities using GitHub's private vulnerability reporting on this repository (**Security** tab → **Report a vulnerability**). This lets us discuss and fix the issue before it is disclosed publicly.

If you cannot use GitHub's private reporting, email **info@reqquest.dev** with as much detail as possible: steps to reproduce, affected version, and potential impact.

Please do not open a public issue for a suspected vulnerability.

## Scope

This policy covers the files of the toolkit package — the `boundary` listed in [`toolkit-manifest.json`](toolkit-manifest.json).

## Response

We aim to acknowledge new reports within 5 business days.
