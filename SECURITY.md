# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities using [GitHub's private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability) on this repository (**Security** tab → **Report a vulnerability**). This lets us discuss and fix the issue before it is disclosed publicly.

If you cannot use GitHub's private reporting, email **info@reqquest.dev** with as much detail as possible: steps to reproduce, affected version, and potential impact.

Please do not open a public issue for a suspected vulnerability.

## Scope

This policy covers the reqQuest Framework toolkit: the validator (`.reqq/validator/reqq_validate_stdlib.py`), the schemas under `.reqq/schema/`, the packaging script (`scripts/pack-toolkit.py`), and the GitHub Actions workflows in this repository.

## Response

We aim to acknowledge new reports within 5 business days.
