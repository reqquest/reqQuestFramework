# Project rules — requirements

Rules of this project for AI agents working in `requirements/`. They extend
[`AGENTS.md`](AGENTS.md) and take precedence over it when the two conflict. This file is
yours: the toolkit installs it once and `upgrade` never touches it.

Keep each rule short, imperative and checkable. Replace the examples with your own rules.

## Domain categories

- Example: "Put booking rules in `functional/BOOKING/` and payment rules in
  `functional/PAYMENT/`."

## Exceptions

- Example: "Requirements in `policies/` quote the regulation verbatim; never rephrase them."
