# ADR — Architecture Decision Records

The numbering convention adopted as the default in this starter kit: `ADR-<CATEGORY>-NNN` (see [`conventions.md`](https://github.com/reqquest/reqQuestFramework/blob/main/docs/framework/conventions.md), section 2). An alternative the methodology allows: globally sequential `ADR-NNNN` without the category segment — the choice depends on whether the repository has enough decisions in different areas for segmentation to make sense.
