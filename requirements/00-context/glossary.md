# Glossary

> Example file (fictional domain: meeting room booking system) — see [`../../docs/artifacts-and-structure.md`](../../docs/artifacts-and-structure.md), section "Glossaries", for this file's role in the methodology.

| Term | Definition |
|---|---|
| **Booking** | A time slot assigned to one room and one employee, preventing another booking of the same room in the same slot. |
| **Booking conflict** | An attempt to create two bookings for the same room with overlapping time slots. |
| **Long booking** | A booking lasting more than 4 hours — subject to an additional approval rule, see [`POL-DEMO-001`](../policies/POL-DEMO-001.md). |
