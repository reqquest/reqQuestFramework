# Stakeholders

> Example file (fictional domain: meeting room booking system) — replace with your project's real stakeholder list.

| Stakeholder | Role | Interest |
|---|---|---|
| Employee | End user | Fast, error-free room booking |
| Front desk | Current process owner | Relief from manually managing bookings |
| IT department | System operator | Maintainability, no emergency escalations |
| Office administrator | Manages exceptions (long bookings, conflicts) | Visibility and control over exceptions — see [`POL-DEMO-001`](../policies/POL-DEMO-001.md) |
