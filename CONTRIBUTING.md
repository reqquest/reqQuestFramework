# Contributing to the reqQuest Framework

Thanks for your interest in the reqQuest Framework.

## Pull requests are not accepted

This repository is published from reqQuest's own working repository, and its content is replaced with every toolkit release. A pull request cannot be merged here: it would be overwritten by the next release.

## Reporting issues

Issues are welcome. Open a GitHub Issue describing the problem or proposal. For bugs, include steps to reproduce, the toolkit version (`toolkit_version` in `.reqq/toolkit.lock`), and what you expected instead. For methodology or toolkit proposals, explain the concrete pain point the change addresses.

To report a security vulnerability, do not open an issue — follow [`SECURITY.md`](SECURITY.md).

## Code of Conduct

This project follows the [Code of Conduct](CODE_OF_CONDUCT.md). By participating, you agree to abide by it.
